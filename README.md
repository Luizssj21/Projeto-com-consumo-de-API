# Projeto: Consumo de API com Fetch 🌐

Este projeto foi desenvolvido com base nos conceitos da aula **[APRENDA FETCH API DE JAVASCRIPT COM PROJETO](https://www.youtube.com/)** do canal Hora de Codar. O objetivo principal é demonstrar na prática como consumir uma API REST, gerenciar os dados recebidos e exibi-los de forma dinâmica na interface do usuário.

## 🚀 Tecnologias Utilizadas

- **HTML5:** Estruturação semântica da página.
- **CSS3:** Estilização da interface.
- **JavaScript (ES6+):** Lógica principal, focada inteiramente na integração com APIs.

## 🎯 Funcionalidades e Aprendizados

- Realização de requisições HTTP assíncronas utilizando a `Fetch API`.
- Uso de `async / await` para um código mais limpo e legível.
- Tratamento prático de erros e exceções de rede utilizando `try...catch`.
- Resolução de Promises e conversão de respostas para o formato JSON.
- Manipulação do DOM para criar e injetar elementos HTML dinamicamente com base nos dados da API (como listas ou cards).

## 🛠️ Como executar o projeto

1. Faça o clone deste repositório:
   ```bash
   git clone https://github.com/Luizssj21/Projeto-com-consumo-de-API.git
   ```

2. Navegue até o diretório do projeto:
   ```bash
   cd Projeto-com-consumo-de-API
   ```

3. Abra o arquivo `index.html` em seu navegador.
